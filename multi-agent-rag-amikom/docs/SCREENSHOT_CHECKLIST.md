# Screenshot Checklist — Multi-Agent RAG AMIKOM V1.1

Berikut adalah panduan screenshot yang perlu diambil untuk penyusunan Laporan UAS:

1. **UI Chat Interaktif**: Tampilan antarmuka utama pada `http://localhost:8000/ui`.
2. **Swagger API Documentation**: Dokumentasi OpenAPI pada `http://localhost:8000/docs`.
3. **Readiness Endpoint**: Response JSON dari `http://localhost:8000/api/v1/readiness`.
4. **Health Endpoint**: Response JSON dari `http://localhost:8000/api/v1/health`.
5. **Single Academic Query**: Contoh pertanyaan kurikulum/SKS pada UI.
6. **Current Schedule Query**: Contoh pertanyaan jadwal aktif semester berjalan.
7. **Historical Schedule Query**: Contoh pertanyaan jadwal arsip/lampau.
8. **Administration Query**: Contoh pertanyaan prosedur pengajuan cuti/KRS manual.
9. **Multi-Intent Query**: Contoh pertanyaan kombinasi Akademik + Administrasi.
10. **Citation Panel**: Tampilan panel sitasi (`source_id`, `chunk_id`, `locator`).
11. **PII Refusal**: Tampilan penolakan saat input memuat data pribadi/NIM.
12. **Conflict Escalation**: Tampilan respon eskalasi pada kasus ambiguitas IPK 2.00.
13. **Pytest Results**: Hasil eksekusi pengujian otomatis pada terminal (`python -m pytest`).
14. **Folder Structure Final**: Tampilan pohon direktori repository `multi-agent-rag-amikom/`.
